C Charker

Charker.

在 Mac 上查看 Anker Prime 160W 与 250W 的实时功率、端口状态和本地能耗记录。

macOS 14 或更高版本；A2345 云端连接需要 macOS 15 或更高版本。

获取 Charker

  • 下载最新版
  • 使用 Homebrew：brew install --cask qzz0518/tap/charker
  • 在 GitHub 查看源码
  • 报告问题
Charker on GitHub

独立互操作性项目，与 Anker 无关联。

功能概览

  • 实时功率
  • 端口状态
  • 本地能耗记录
  • 原生 Sparkle 更新
