为什么做Purpose

把充电器的小屏幕
搬到 Mac 上 The charger’s tiny screen,
now on your Mac

充电器的屏幕只有一小块，想知道每个口在出多少瓦，得凑过去看。所以我做了 Charker。

每个口的电压、电流和功率都看得到。3D 模型可以拖着转。菜单栏里随时能瞄一眼总功率。用电量和电费按天记下来。

也能直接在 Mac 上开关端口、设倒计时、换充电模式。没有 Charker 服务器，不收集使用数据，代码在 GitHub 上。

To see how many watts each port is putting out, you have to lean over and look at the charger. So I built Charker.

Every port shows its voltage, current and power. You can drag the 3D model around. Total power stays in the menu bar. Energy use and cost are logged each day.

You can also turn ports on and off, set countdowns and change charging modes from your Mac. There is no Charker server and no usage data is collected. The code is on GitHub.
